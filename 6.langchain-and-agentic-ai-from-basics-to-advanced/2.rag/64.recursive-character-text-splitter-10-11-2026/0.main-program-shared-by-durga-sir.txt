    print(f"Chunk {index}: {chunk}")
    print("Length:", len(chunk))

Because CharacterTextSplitter is designed around one configured separator.
We can  solves this problem by trying multiple separators in order. For this we required to use: RecursiveCharacterTextSplitter

3. Why Do We Need RecursiveCharacterTextSplitter?
-------------------------------------------------
Suppose we are processing a company policy document containing:
•	Multiple paragraphs
•	Multiple lines
•	Long sentences
•	Short sentences
•	Some very long words or codes
If we split only at paragraph boundaries, a very large paragraph may remain.
If we split only at newline boundaries, a very long line may remain.
If we split only at spaces, a very long word may remain.

First try paragraph boundary
           |
           v
If a piece is still too large
           |
           v
Try newline boundary
           |
           v
If still too large
           |
           v
Try space boundary
           |
           v
If still too large
           |
           v
Split character by character

That is the basic idea behind RecursiveCharacterTextSplitter

What Is RecursiveCharacterTextSplitter?
----------------------------------------
RecursiveCharacterTextSplitter is a LangChain class that divides text into smaller chunks by trying multiple separators in a specified order and recursively splitting oversized pieces when necessary.

bserve carefully.
There are three important ideas in this definition:
1.	Multiple separators
2.	Priority order
3.	Recursive splitting of oversized pieces

CharacterTextSplitter vs RecursiveCharacterTextSplitter
----------------------------------------------------------
Feature	        CharacterTextSplitter	         RecursiveCharacterTextSplitter
Main strategy	 One configured separator	Ordered list of separators
Parameter	separator	               separators
Recursive splitting	No	                  Yes
Long indivisible piece	Can remain oversized	Can be divided using fallback separators
Default boundary	"\n\n"	                   ["\n\n", "\n", " ", ""]
Common use	Simple structured text	       General text documents
Flexibility	Lower	                      Higher


10.4 Important Parameters
--------------------------
Parameter	Default value	Purpose
chunk_size	4000	Target maximum chunk length
chunk_overlap	200	Target overlap between chunks
separators	["\n\n", "\n", " ", ""]	Separator priority
keep_separator	True	Retain the separator, normally at the start of the following piece
length_function	len	Measure chunk length
is_separator_regex	False	Treat separators as literal text unless enabled
strip_whitespace	True	Strip outer whitespace from merged chunks
add_start_index	False	Include original character position in Document metadata


Program 1 — First RecursiveCharacterTextSplitter Program
---------------------------------------------------------
Goal: Prove that recursive splitting can divide text even when there are no spaces or paragraph boundaries.

from langchain_text_splitters import (
    RecursiveCharacterTextSplitter
)


# ========================================
# ORIGINAL TEXT
# ========================================

text = "ABCDEFGHIJKL"


# ========================================
# CREATE TEXT SPLITTER
# ========================================

splitter = RecursiveCharacterTextSplitter(
    chunk_size=5,
    chunk_overlap=0
)


# ========================================
# SPLIT TEXT
# ========================================

chunks = splitter.split_text(text)


# ========================================
# DISPLAY RESULTS

print("RETURN TYPE:", type(chunks))

        f"| Length: {len(chunk)}"
    )

-------------------------------------------------------------------
from langchain_text_splitters import (
    CharacterTextSplitter,
    RecursiveCharacterTextSplitter
)


# ========================================
# ORIGINAL TEXT
# ========================================

text = "ABCDEFGHIJKL"


# ========================================
# APPROACH 1 — CHARACTER TEXT SPLITTER
# ========================================

splitter1 = CharacterTextSplitter(
    separator="\n\n",
    chunk_size=5,
    chunk_overlap=0
)

chunks1 = splitter1.split_text(text)


# ========================================
# APPROACH 2 — RECURSIVE TEXT SPLITTER
# ========================================

splitter2 = RecursiveCharacterTextSplitter(
    chunk_size=5,
    chunk_overlap=0
)

chunks2 = splitter2.split_text(text)


# ========================================
# DISPLAY RESULTS
# ========================================

print("CHARACTER TEXT SPLITTER")
print("-----------------------")

print("Total Chunks:", len(chunks1))
print(chunks1)


print("\nRECURSIVE CHARACTER TEXT SPLITTER")
print("---------------------------------")

print("Total Chunks:", len(chunks2))
print(chunks2)

Program 7 — Splitting LangChain Document Objects
-------------------------------------------------
from langchain_core.documents import Document

from langchain_text_splitters import (
    RecursiveCharacterTextSplitter
)


# ========================================
# CREATE DOCUMENT
# ========================================

document = Document(
    page_content="ABCDEFGHIJKL",

    metadata={
        "source": "company_policy.txt",
        "department": "HR"
    }
)


# ========================================
# CREATE TEXT SPLITTER
# ========================================

splitter = RecursiveCharacterTextSplitter(
    chunk_size=5,
    chunk_overlap=2,
    separators=[""],
    add_start_index=True
)


# ========================================
# SPLIT DOCUMENT
# ========================================

chunks = splitter.split_documents(
    [document]
)


# ========================================
# DISPLAY RESULTS
# ========================================

print("TOTAL CHUNKS:", len(chunks))


for index, chunk in enumerate(chunks, start=1):

    print(f"\nCHUNK {index}")

    print("CONTENT:", chunk.page_content)

    print("METADATA:", chunk.metadata)

    print("TYPE:", type(chunk).__name__)

Program 8 — Practical Company Policy Document
----------------------------------------------
from langchain_core.documents import Document

from langchain_text_splitters import (
    RecursiveCharacterTextSplitter
)


# ========================================
# CREATE SAMPLE COMPANY POLICY DOCUMENT
# ========================================

document = Document(
    page_content=(
        "ATTENDANCE POLICY\n"
        "Employees must report by 9 AM.\n\n"
        "LEAVE POLICY\n"
        "Employees receive 12 casual leaves.\n\n"
        "WORK FROM HOME\n"
        "Manager approval is required."
    ),
    metadata={
        "source": "company_policy.txt"
    }
)


# ========================================
# CREATE RECURSIVE SPLITTER
# ========================================

splitter = RecursiveCharacterTextSplitter(
    chunk_size=60,
    chunk_overlap=0,
    separators=["\n\n", "\n", " ", ""]
)


# ========================================
# SPLIT DOCUMENT
# ========================================

chunks = splitter.split_documents([document])


# ========================================
# DISPLAY RESULTS
# ========================================

print("TOTAL CHUNKS:", len(chunks))


for index, chunk in enumerate(chunks, start=1):

    print(f"\nCHUNK {index}")
    print("-" * 30)

    print(chunk.page_content)

    print("LENGTH:", len(chunk.page_content))

    print("SOURCE:", chunk.metadata["source"])
