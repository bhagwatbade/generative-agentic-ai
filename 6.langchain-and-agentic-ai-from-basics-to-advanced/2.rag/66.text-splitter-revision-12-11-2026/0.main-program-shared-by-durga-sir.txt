Text Splitting Experiments: Chunk Size, Chunk Overlap & Choosing the Right Splitting Strategy
----------------------------------------------------------------
Concept     	Meaning
Chunk	        One smaller piece of text
Chunk size	Target maximum length of a chunk
Chunk overlap	Target repeated content between neighbouring chunks
Separator	Possible boundary for dividing text
-------------
3. Why Do We Need Experiments in Text Splitting?
------------------------------------------------
Friends, imagine a company with a 500-page policy document.
We are building a RAG application.
A user asks:
"How many casual leaves are allowed every year?"
Our application must find the leave policy information and send relevant context to an LLM.
But suppose the document was split into very small chunks.
One chunk contains:
Employees are eligible for

Another chunk contains:
12 casual leaves every year.

The complete information is separated.
Now suppose we use a very large chunk.

That chunk may contain:
•	Attendance rules
•	Salary rules
•	Leave rules
•	Security rules
•	Travel rules
The required answer is present, but a large amount of unrelated information is also included.
We need a balance.

The objective is not simply to produce the maximum number of chunks or minimum number of chunks.
Our objective is to produce useful chunks.

Student Question: Sir, what is a useful chunk?
A useful chunk contains enough related information for the application to process or retrieve it effectively, without unnecessary information where possible.

Small Chunk Size
-----------------
With smaller chunks:
•	More chunks may be produced.
•	Each chunk contains less information.
•	Retrieval may become more focused.
•	Related information may be split across chunks.

Large Chunk Size
------------------
With larger chunks:
•	Fewer chunks may be produced.
•	Each chunk contains more context.
•	More unrelated information may be included.
•	Some questions may benefit from the additional surrounding context.

Very Important Clarification
------------------------------
Friends, small chunks are not automatically better.
Large chunks are also not automatically better.
The right choice depends on our application.

Program 1 — One Large Chunk vs Multiple Chunks
-----------------------------------------------
Goal: Observe how changing chunk size changes the number of chunks.
We will use a string containing 20 characters.

from langchain_text_splitters import (
    RecursiveCharacterTextSplitter
)


# ========================================
# ORIGINAL TEXT
# ========================================

text = "ABCDEFGHIJKLMNOPQRST"


# ========================================
# DIFFERENT CHUNK SIZES
# ========================================

chunk_sizes = [20, 10, 5]


# ========================================
# RUN EXPERIMENTS
# ========================================

for size in chunk_sizes:

    splitter = RecursiveCharacterTextSplitter(
        separators=[""],
        chunk_size=size,
        chunk_overlap=0
    )

    chunks = splitter.split_text(text)

    print("\nCHUNK SIZE:", size)
    print("TOTAL CHUNKS:", len(chunks))

    for index, chunk in enumerate(chunks, start=1):

        print(
            f"Chunk {index}: {chunk}"
        )

Program 5 — Real-Life Experiment Using Company Policies
---------------------------------------------------------
Friends, until now we used alphabet examples.
That was useful for understanding exact chunk sizes and overlap.
Now let us use meaningful text.
Suppose our document contains three company policies.

from langchain_core.documents import Document

from langchain_text_splitters import (
    RecursiveCharacterTextSplitter
)


# ========================================
# CREATE COMPANY POLICY DOCUMENT
# ========================================

document = Document(
    page_content=(
        "ATTENDANCE POLICY\n"
        "Employees must report to the office by 9 AM.\n\n"

        "LEAVE POLICY\n"
        "Employees receive 12 casual leaves every year.\n\n"

        "WORK FROM HOME POLICY\n"
        "Employees need manager approval to work from home."
    ),
    metadata={
        "source": "company_policy.txt",
        "department": "HR"
    }
)


# ========================================
# DIFFERENT CHUNK SIZES
# ========================================

chunk_sizes = [40, 80, 200]


# ========================================
# RUN EXPERIMENTS
# ========================================

for size in chunk_sizes:

    print("\n" + "=" * 45)
    print("CHUNK SIZE:", size)
    print("=" * 45)

    splitter = RecursiveCharacterTextSplitter(
        chunk_size=size,
        chunk_overlap=0
    )

    chunks = splitter.split_documents(
        [document]
    )

    print("TOTAL CHUNKS:", len(chunks))

    for index, chunk in enumerate(
        chunks,
        start=1
    ):

        print(f"\nCHUNK {index}")
        print("-" * 30)

        print(chunk.page_content)

        print(
            "LENGTH:",
            len(chunk.page_content)
        )

        print(
            "SOURCE:",
            chunk.metadata["source"]
        )

Program-1: Choosing the Right Chunk Size and Chunk Overlap Based on Input Data (FAQ Example)
====================================================================================
from langchain_text_splitters import RecursiveCharacterTextSplitter

# STEP 1: Input data - 3 independent Q&A pairs

faqs = [
    """Q1: What is Python?
A1: Python is a high-level programming language. It is widely used in web development, artificial intelligence, data analysis and automation. Its syntax is easy to read, so many beginners start programming with Python. It also offers many ready-made libraries for practical projects.""",

    """Q2: What is Java?
A2: Java is an object-oriented programming language. Developers use it to build enterprise applications, backend services and many large systems. Java programs normally run on the Java Virtual Machine, which helps the same compiled program work on different supported operating systems.""",

    """Q3: What is SQL?
A3: SQL stands for Structured Query Language. We use it to work with relational databases. Common operations include reading rows using SELECT, inserting records using INSERT, modifying data using UPDATE and removing records using DELETE. SQL helps applications manage structured data."""
]

text = "\n\n".join(faqs)

print("Q&A lengths:", [len(faq) for faq in faqs])

# STEP 2: Compare different chunk sizes and overlaps

for size, overlap in [(150, 0), (600, 0), (600, 150), (2000, 0)]:

    splitter = RecursiveCharacterTextSplitter(
        chunk_size=size,
        chunk_overlap=overlap,
        separators=["\n\n", "\n", " ", ""],
        keep_separator=False
    )

    chunks = splitter.split_text(text)

    print(f"\nChunk Size: {size}, Overlap: {overlap}")
    print("Total Chunks:", len(chunks))

    for i, chunk in enumerate(chunks, 1):
        print(f"\nChunk {i}:")
        print(chunk)
        print("-" * 40)
